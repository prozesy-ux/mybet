Step 2 : Choose the product type you want to test

Step 3 : Press the 'Start Testing' button

Step 4 : According the report fix the api logic until Need To Fix Count equal to 0


After start test, page will reload every 30 seconds, you can keep check the result. Or can wait all test are done will have a page alert to let you know.

Hint :

If 'Checked' column shows 'Need to fix !'

You need to check the steps above and you will know how to fix it

ex : If NO 'Sports-2-7' need to fix, then you need to check NO 'Sports-2-1' to NO 'Sports-2-7', TestDescription will told you the testing flow

Resend Mechanism

Normally we do have the resend mechanism in our API.

When your side response with ErrorCode that is not equal to 0, we will do the resend with the same API request.

And will stop resend once your side response with ErrorCode in (6, 2001, 2002, 2003).
